# Data license

The map data in this project (community names, boundaries and attributes) is made available under the
**Open Database License (ODbL) 1.0**: https://opendatacommons.org/licenses/odbl/1-0/

You are free to share, adapt and use the data, including commercially, as long as you:
- **Attribute:** credit "Gated Manila contributors" and, where the data derives from OpenStreetMap, "© OpenStreetMap contributors".
- **Share alike:** publish adapted databases under the ODbL.
- **Keep open:** don't use technical restrictions that stop others from using the open data.

## OpenStreetMap-derived data
Some boundaries are imported from OpenStreetMap, © OpenStreetMap contributors, available under the ODbL
(https://www.openstreetmap.org/copyright). Each imported record keeps a link to its OSM source in its `source` field.

## Contributor submissions
By submitting data, contributors agree it may be published under the ODbL. Contributors must not copy boundaries or
other data from sources that forbid it (for example Google Maps or other proprietary map products). Draw shapes
yourself, or use open sources such as OpenStreetMap.

## What is not included
The map background tiles are provided by OpenStreetMap and are subject to their own terms.
Source code is licensed separately (see `LICENSE`).
